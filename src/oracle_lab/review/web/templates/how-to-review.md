## How to review

You are rating the judge's answers. You are not answering the questions
yourself.

Work one problem at a time: its classification first, then each run. Read the
Problem tab before rating: the issue, the fix, and the reference tests.

For each item, read the judge's answer and its justification, check them against
the evidence, and choose:

${ratings}

Rate each item on its own. If an earlier answer is wrong, rate the later ones as
if it were right. The stage rubric defines every question and label.

On a Generation Judgment, the judge also decided whether each start-list failure
mode is present in the agent's trace. Present ones cite trace steps; their links
open the step in the Agent trace tab. Agree or disagree with every decision,
absent ones too. If you see a failure mode that none of the labels describes,
add it under Your other labels.

### Keys

- `1` and `2` agree or disagree with the selected item.
- `j` and `k` move between items.
- On the Agent trace tab, `↑` and `↓` move between events, and `Esc` clears the
  selection.
- `Ctrl` `P` finds a file.

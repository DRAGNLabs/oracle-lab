## How to review a classification

You rate the classifier's answers. You do not answer the questions yourself.

1. Review the problem. On the left, the **Problem** tab has the issue, the golden
   patch (the fix), and the reference tests.
2. Review the code. The **Files** tab shows the buggy repository. Lines the fix
   changes are marked in red. **Compare buggy and golden** shows the fix side by
   side.
3. Review the rubric. On the left, the **Stage rubric** tab defines every
   question and its answers.
4. Rate each answer. On the right, read the classifier's answer and its
   justification, then choose:

${ratings}

   Each disagree needs a short reason: what the right answer is, and why. Rate
   each answer on its own. If an earlier answer is wrong, rate the later ones as
   if it were right.

### Keys

- `1` and `2` agree or disagree with the selected answer.
- `j` and `k` move between answers.
- `Ctrl` `P` finds a file.

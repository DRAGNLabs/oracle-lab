How to review

You are rating the judge's answers. You are not answering the questions yourself.

Work one problem at a time: its classification first, then each run. Read the Problem tab before rating: the issue, the fix, and the reference tests.

For each question, read the judge's answer and its justification, check them against the evidence, and choose one rating:

Rate each question on its own. If an earlier answer is wrong, rate the later ones as if it were right. The stage rubric defines every question and label.
